# FP&A Personal AI Assistant – Calendar Dataset

This repository contains structured calendar, holiday, and rule-based datasets
used by an AI-powered FP&A Personal Assistant integrated with n8n.

## Data Sources
- Google Calendar (exported & normalized)
- Bangladesh public holidays

## Usage
- Imported into n8n
- Used by AI agent for:
  - Task prioritization
  - Deadline tracking
  - Holiday-aware work planning
  - FP&A cycle reminders
